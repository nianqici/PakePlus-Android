ℹ️ 说明

· 数据保存在本机 IndexedDB 数据库（kid_star_points），完全离线，不联网；换环境/清缓存会丢失，重要数据请先导出 JSON 或 CSV 备份。
· 家长端密码支持 字母 + 数字（4~20 位，区分大小写），初始密码 Star2026，进入后请立刻修改。
· 安全：家长端退出后即锁定，每次进入都要重新输入密码；闲置 15 分钟也会自动锁定，刷新页面同理。
· 忘记密码：点「通过密保问题重置」，答对密保才能重置为初始密码；默认问题「我的生日是？」，答案在家长端「🛡 密保设置」里可随时修改。
· 任务分三档：基础档（计入完成率/连续打卡）、挑战档（配分更高，不计完成率）、隐藏档（按当日完成率随机解锁彩蛋，每天最多 1 个）。
· 时间加成：任务设定截止时间（如 19:30），在此之前标记完成，家长确认时额外加分。
· 多孩：点顶栏头像切换孩子，家长端「孩子管理」可增删改名，各孩子数据完全独立。
· 打包 exe：用 Electron / Nativefier / HTML Executable 等工具把本 HTML 文件封装即可，数据逻辑无需改动。
